# ParkEase

Smart Parking Management System

## Technologies Used
- HTML
- CSS
- PHP
- MySQL
- XAMPP

## Modules
- User Registration/Login
- Vehicle Management
- Parking Slot Management
- Booking Management
- Payment Management
- Parking Records
- Admin Management

## Main Feature
Prevents overlapping bookings for the same parking slot, date and time.

## How to Run
1. Install XAMPP
2. Copy ParkEase into htdocs
3. Start Apache and MySQL
4. Create the ParkEase database
5. Import the SQL file
6. Open http://localhost/ParkEase/
